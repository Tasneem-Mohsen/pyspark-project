# Dataset

## COVID-19 Dataset

This project uses the **Our World in Data COVID-19 Dataset**, available on Kaggle.

- **Dataset Source:** [Our World in Data COVID-19 Dataset on Kaggle](https://www.kaggle.com/datasets/caesarmario/our-world-in-data-covid19-dataset)
- **Topic:** COVID-19 cases, deaths, vaccinations, and related statistics.
- **Purpose:** To analyze COVID-19 trends and explore patterns across countries and over time.

## How to Download

1. Open the [dataset page on Kaggle](https://www.kaggle.com/datasets/caesarmario/our-world-in-data-covid19-dataset).
2. Sign in to Kaggle if required.
3. Download the dataset.
4. Extract the downloaded files and update the file path in the notebook.

## Notes

The dataset is not stored directly in this repository. Please download it from the original source before running the notebook.
